v0.4.0: Restored original Gear Hunter 1600x900 UI in Navigator. Original Midnight border, model/slots, tabs, panels, showcase, and support center loaded inside one addon. MapHub discoveries remain integrated in the Map page. Single addon and minimap entry.

INSTALL ONLY GearHunterNavigator into _retail_/Interface/AddOns/
Remove old GearHunter and MapHub addon FOLDERS if installed to avoid duplicate tools,
then restart WoW. Preserve your WTF folder (your old saved variables remain there).
Open with /ghnav. Left menu Gear Hunter -> tabs for Gear Search, Boss Loot,
Transmog, Hunt List, Farm Route, Smart Picks, Upgrade Planner, Weekly Farm,
Alt Tracker, Collection Dashboard and Farm Session. Map -> rare/treasure explorer,
and OPEN FULL WORLD MAP for live map pins. Original Gear Hunter's saved variables
are migrated if its global GearHunterDB is already loaded in this game session,
otherwise its existing data are not overwritten; a migration helper may be needed.
The project has not been tested in a running WoW client.
