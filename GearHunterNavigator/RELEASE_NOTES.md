# Gear Hunter Navigator v0.5.5

- Improved achievement loading with guarded WoW API calls.
- Improved earned/incomplete status checks, including supported account-wide completion state.
- Search by achievement name or ID and filter by achievement category.
- Safer achievement criteria/progress display for missing records.
- Toggle tracking or untracking with Blizzard APIs where available.
- Refresh achievement data on earned, criteria update, and login events.
- Retains the v0.5.3 working map-art rendering, rare locations, and all previous artwork.

The addon is statically packaged by GitHub Actions. In-game behavior must be verified inside WoW.
